# Joy Roy - Junior Backend Developer Portfolio

## Run on your computer
1. Install Node.js (LTS) from https://nodejs.org
2. Open this folder in a terminal (VS Code: Terminal > New Terminal)
3. `npm install`
4. `npm run dev`  -> open the link it shows (http://localhost:5173)

## What to edit (only src/App.jsx, top of the file)
- PROFILE  : name, email, location, tagline
- SOCIALS  : your GitHub, LinkedIn, Facebook links
- ABOUT, JOURNEY, SKILLS, PROJECTS : your real content

## Add your files (folder: public/)
- profile.jpg  -> your photo
- cv.pdf       -> your CV

## Put it online (free)
`npm run build` then upload the `dist` folder to Netlify (drag and drop),
or push the project to GitHub and import it on Vercel.
